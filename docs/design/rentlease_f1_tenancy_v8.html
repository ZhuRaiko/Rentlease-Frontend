Feature 1 · Tenancy screens

Tenancy tab and tenancy details, tenant and landlord, with the cancelled-rental fix. Same screens as v8, split out so this feature can be built on its own.

What this feature needs

  • Backend: none. Frontend only.
  • Stand-ins until later features land: Report an issue opens today's rent and maintenance screen (Feature 6 replaces it). Open property opens today's property screen (Feature 2 replaces it). The landlord row is not tappable and shows no check (Feature 5). The rent card shows the schedule and next due date only, without I've paid (Feature 3).
  • Cancelled fix: calls the existing respond_rental_reservation(..., 'cancel'), then opens the request screen.
