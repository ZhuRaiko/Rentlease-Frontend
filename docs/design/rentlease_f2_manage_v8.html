Manage property · occupied (new, replaces "Manage Status")

  • Today the screen is: title, status text, completeness, one date, price estimate, buttons. Now it is a hub: needs you → tenant → rent → actions.
  • Needs you is the strongest element: amber, at the top, only when something is waiting. Items link straight to the maintenance request or end request.
  • Tenant card: check, rating, stays, message. Landlords can read this because the audit shows tenancy reads already work for participants.
  • Rent row with Mark received uses rent_obligations statuses that already exist (tenant_marked_paid → landlord_acknowledged) but need an RPC. If cut, show only next due date.
  • Quick-action tiles are secondary, with colored icon wells that match state. Pause/archive stay disabled while a tenancy is active.
